# Kata Sprint

A timed brain-puzzle word game in Bahasa Melayu and English.

- **Language:** Bahasa Melayu or English — the whole game (words, clues, instructions) follows your choice
- **Levels:** Mudah / Easy, Sederhana / Medium, Sukar / Hard, Super Sukar / Super Hard
- **Puzzles:** unscramble, missing letters, odd one out, guess the word
- **Scoreboard:** shared online board (Supabase) with top players, recent games and an "only me" filter

## Play

Open `index.html` in a browser. No build step or install needed.
