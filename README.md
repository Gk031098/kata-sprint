# Kata Sprint

A timed brain-puzzle word game in Bahasa Melayu and English.

- **Word language:** Bahasa Melayu, English, or Campur (mixed, adds translation puzzles)
- **Instruction language:** Bahasa Melayu or English
- **Levels:** Mudah / Easy, Sederhana / Medium, Sukar / Hard, Super Sukar / Super Hard
- **Puzzles:** unscramble, missing letters, odd one out, guess the word, translate

## Play

Open `index.html` in a browser. No build step or install needed.
